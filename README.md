# Sigma Seller Community

Бесплатный сервис для продавцов Wildberries: аналитика, финансы, отзывы, поставки, карточки, ИИ-помощник и творческая студия. Исходный код доступен по лицензии PolyForm Noncommercial 1.0.0. Это source-available проект, а не Open Source в определении OSI.

## Оплата

Сам сервис не принимает оплату: подписки, пополнение внутреннего баланса и автоматические продления отключены. Для ИИ владелец магазина добавляет **свой** ключ в «Настройки ИИ». Провайдер может взимать плату с владельца ключа за запросы команды и включённых автоматизаций. Лимиты расходов задаются в аккаунте провайдера. Ключи разных магазинов хранятся отдельно и зашифрованы; общего резервного ключа нет.

Расходы партнёрской интеграции WB оплачивает оператор сайта, если он принимает платный тариф WB. Сервис не перевыставляет эти расходы продавцам. Это отдельная статья расходов, не связанная с ключами ИИ продавцов.

Сервер, домен, дисковое пространство и интернет нужны для работы. Публичный доступ не означает неограниченную мощность. Эта версия не включает автоматическое расширение инфраструктуры. ИИ-провайдеры и Wildberries могут ограничивать доступность отдельных моделей, методов и регионов.

## Быстрый старт продавца

1. На главной странице доступны инструкция по использованию сервиса и форма регистрации по email и паролю. Справочник объясняет оплату, подключение WB, работу с данными, оба способа подключения ИИ, подтверждения и управление доступом. Вход переключается в той же форме. Сохраните личный код восстановления: он нужен вместо почтового восстановления.
2. Подключите свой магазин WB через доступный для сервиса тип токена и дождитесь синхронизации.
3. Аналитика и обычные инструменты доступны без ИИ-ключа. Для чата, агентов, отзывов и SEO добавьте Anthropic. Для соответствующих инструментов студии — OpenAI или Runway; Google AI используется инструментами Gemini. Voyage/Jina нужны для семантического поиска, Tavily — для веб-поиска.
4. При подключении ключа подтвердите, что расходы у провайдера несёте вы. В настройках безопасности можно заменить код восстановления, подтвердив текущий пароль.

После регистрации сразу открывается подключение магазина, после завершения синхронизации — кабинет. Повторный вход с подключённым магазином ведёт в кабинет. Старые ссылки `/auth/register`, `/auth/login`, `/landing-v2` и `/landing-v4` ведут на единую стартовую страницу. Подключение внешнего ИИ сохраняет свой шаг после авторизации.

На стартовой странице иллюстрации инструментов при прокрутке собираются в общий кабинет. Анимация работает локально в браузере без сторонних видео и CDN; на телефонах не перекрывает форму и учитывает настройку уменьшения движения.

Не передавайте личный токен WB облачному сервису, если правила WB предусматривают для этого сценария сервисный токен или OAuth. Подключение OAuth требует регистрации сервиса в программе WB; наличие исходников само по себе не даёт такой регистрации. См. [документацию WB](https://seller.wildberries.ru/instructions/ru/ru/material/oauth20-api-integration).

## Два способа общаться с ИИ

В «Подключениях ИИ» подключите Sigma Seller к своему ChatGPT или Claude через MCP. Внешний чат получает только разрешённые данные одного магазина. Встроенный «Чат с магазином» поддерживает ключи OpenAI и Anthropic продавца. Черновики и предложения доступны в одном разделе; отправка изменений WB требует отдельного подтверждения и по умолчанию выключена. Использование подписки ChatGPT внутри общего сайта пока недоступно без официального допуска провайдера. Подробности и настройка: [MCP.md](MCP.md).

## Установка на собственном сервере

Требования: Node.js 22 или 24, PostgreSQL с расширением pgvector, Redis, npm и pnpm 10. Установка пакетов требует интернета. Runtime-файлы пользователей хранятся локально в `pulse-api/storage`; резервные копии и HTTPS настраивает оператор.

1. Создайте **новую пустую** базу PostgreSQL. Установите расширения `vector`, `pgcrypto` и `citext`. Не используйте для первого запуска существующую базу с данными.
2. Скопируйте `pulse-api/.env.example` в `pulse-api/.env`, а `pulse-web/.env.example` — в `pulse-web/.env.local`. Заполните адреса и отдельные случайные секреты. Секрет для шифрования обязателен; не меняйте его после сохранения ключей без отдельной миграции.
3. В `pulse-api`: `pnpm install --frozen-lockfile`, затем `node scripts/init-community-db.mjs`, затем `pnpm build`.
4. В `pulse-web`: `npm ci`, затем `npm run build`. Постобработка добавляет статические файлы в автономную сборку.
5. Запустите API из `pulse-api`: `node dist/server.js`. Запустите сайт из `pulse-web/.next/standalone`: `node server.js` с переменными веб-сервера. Передайте `PORT=3001`, `HOSTNAME=127.0.0.1`, `PULSE_API_BASE=http://127.0.0.1:3000` и внутренний `PULSE_API_KEY`. Веб-прокси не выдаёт этот ключ браузеру.
6. Настройте обратный прокси: сайт → порт 3001, `/storage/` → API на порту 3000. Закройте прямой внешний доступ к PostgreSQL, Redis и API. Для публичного запуска включите HTTPS и `NODE_ENV=production`.

`init-community-db.mjs` отказывается работать с непустой базой. `db/bootstrap.sql` содержит только структуру, без аккаунтов, ключей, платежей и данных продавцов. Начальная структура восстановлена из действующего проекта; новые таблицы добавляются миграциями 0149, 0150 и 0151.

В окружении API и фоновых процессов **нельзя** задавать общие ключи Anthropic/OpenAI/Google/Runway/Voyage/Jina/Tavily/Fal, Resend, внешнего S3, Sentry или LangSmith. При обнаружении таких настроек API откажется запускаться. Удалите их из конфигурации этой установки, не отзывая ключи, которые нужны другим приложениям. WB-токены магазинов добавляются через интерфейс.

Для облачной партнёрской интеграции WB задайте `WB_PARTNER_BILLING_ACCEPTED=1` в окружении API и фоновых процессов, если оператор согласен оплачивать WB API за подключённые магазины. По умолчанию согласие выключено. Оно не разрешает общие платные ключи ИИ, почты или других сервисов и не включает автоматические изменения в WB. При действительно бесплатном договоре поддерживается отдельный флаг `WB_PARTNER_BILLING_VERIFIED_FREE=1`; не используйте его вместо согласия на оплату. Настройки не меняют тариф или договор WB и не устанавливают денежный лимит. Удаление секрета тоже не доказывает прекращения тарификации по существующему договору. См. [официальное сообщение RWB](https://telegram.me/s/rwb_press_service?before=1309).

Для базового запуска достаточно одного процесса API: он запускает фоновые задания. Если запускаете отдельный `node dist/jobs/worker.js`, задайте API `DISABLE_INTERNAL_JOBS=1`, чтобы не удваивать фоновые запросы. Не запускайте две копии на одной Redis-базе и одном расписании.

Синхронизации, запускающие отдельные процессы, выполняются по очереди: `WB_SYNC_CONCURRENCY=1` по умолчанию. Один лимит объединяет обычные, ручные и первоначальные загрузки внутри каждого процесса API или worker. На более мощном сервере можно выбрать 2–4 после проверки памяти; этот параметр не ограничивает число зарегистрированных магазинов и не задаёт лимит оплаты WB.

По умолчанию расписание запускает синхронизацию, но не автоматические изменения цен, фото, рекламы и автоответы. Ручные действия доступны с обычными проверками прав. После проверки сохранённых правил всех магазинов оператор может явно задать `COMMUNITY_READ_ONLY_AUTOMATIONS=0`, чтобы разрешить эти автоматизации. Перед включением обработчиков на старой базе сохраните и отмените накопленные старые запуски; не выполняйте очередь за месяцы одним пакетом.

Удаление фона требует локального Python-сервиса rembg; FBS-печать использует отдельный sidecar, если он настроен. Они не поставляются как платные облачные сервисы. Экспериментальные и административные разделы сохраняют ограничения по ролям. Доступность внешних API и качества ИИ требует проверки с собственными ключами; платные тестовые генерации в процессе подготовки этой версии не выполнялись.

## Проверки

В API: `pnpm exec tsc --noEmit`, `pnpm run test:community`.
В веб-приложении: `npm run build`.
Тесты используют вымышленные ключи и локальную PostgreSQL-совместимую базу PGlite. Исходные интеграционные тесты старой версии в этот пакет не включены: часть из них обращается к работающим сервисам.
